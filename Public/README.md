# Aplikasi Nonton Iklan Terpisah (User & Admin)

Aplikasi ini dibagi menjadi dua file terpisah:
1. `user.html` - Halaman khusus pengguna (misi 30 detik, wallet, top up, dan withdraw).
2. `admin.html` - Halaman khusus admin (manajemen akun/blokir, preview & download bukti pembayaran, kontrol link misi 1-10, dan approval withdraw).

Buka salah satu file di browser web Anda (keduanya saling terhubung melalui LocalStorage).
